## 🎯 当前训练策略

### 核心配置
```python
# 模型
model = "roberta-base"  # 125M参数

# 学习率重启策略
max_lr = 8e-5
min_lr = 5e-6
use_cosine_restarts = True
restart_period = 12  # 每12轮重启

# 训练参数
max_epochs = 80
batch_size = 48
accumulate_grad_batches = 2  # 有效batch=96

# 正则化
weight_decay = 0.005
dropout_rate = 0.05
```

### 预期效果
| Epoch | 预期 mAP@10 |
|-------|-------------|
| 12 | 0.30-0.31 |
| 24 | 0.32-0.33 |
| 36 | 0.34-0.35 |
| 48 | 0.35-0.36 |
| 60 | 0.36-0.37 |
| 72-80 | 0.37-0.40 |

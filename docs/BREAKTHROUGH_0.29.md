# 突破0.29平台期 - 训练配置说明

## 🎯 问题诊断

从你的训练曲线可以看出：
- ✅ **好消息**：从0.25成功提升到0.29，说明之前的优化有效
- ⚠️ **问题**：在step 300（约epoch 15）后进入平台期，持续8个epoch停滞在0.29

**根本原因**：模型陷入**局部最优**，学习率在warmup后持续下降，缺乏"跳出"当前状态的能力

---

## 💡 解决方案：学习率重启 + 强正则化

### 核心策略

#### 1. **Cosine Annealing with Warm Restarts**
```
学习率曲线示意：
     3e-5 ┤     ╱╲      ╱╲      ╱╲      ╱╲
          │    ╱  ╲    ╱  ╲    ╱  ╲    ╱  ╲
          │   ╱    ╲  ╱    ╲  ╱    ╲  ╱    ╲
     1e-6 ┤──╱──────╲╱──────╲╱──────╲╱──────╲──
          └─────────────────────────────────────
          0    15    30    45    60    75    80 (epoch)
          └─warmup─┘└─────每15个epoch重启一次─────┘
```

**原理**：
- 每15个epoch，学习率从最低点重新升高到最大值
- 给模型"重新探索"的机会，跳出局部最优
- 类似"模拟退火"算法，在收敛和探索间平衡

#### 2. **提高学习率**
- `max_lr`: 2e-5 → **3e-5** (提高50%)
- roberta-large需要更大的学习率才能有效更新

#### 3. **增强正则化**
- `weight_decay`: 0.05 → **0.08** (防止过拟合)
- `dropout_rate`: 0.1 → **0.15** (增加随机性)
- `hard_negative_weight`: 0.1 → **0.2** (更难的负样本)
- `label_smoothing`: 0.0 → **0.1** (防止过度自信)

#### 4. **延长训练**
- `max_epochs`: 60 → **80**
- 利用多次学习率重启，每次重启都可能带来新突破

## 🔧 技术细节

### 修改的配置参数

```python
# train.py
--max_epochs 80                    # 延长训练
--warmup_epochs 5                  # 快速warmup
--rampdown_epochs 70               # 更长的训练周期
--max_lr 3e-5                      # 提高学习率
--use_cosine_restarts True         # 启用学习率重启
--restart_period 15                # 每15个epoch重启
--weight_decay 0.08                # 增强正则化
--dropout_rate 0.15                # 增加dropout
--hard_negative_weight 0.2         # 更强的负样本挖掘
--label_smoothing 0.1              # 标签平滑
```

### 修改的代码文件

1. **train.py**
   - 添加 `use_cosine_restarts` 和 `restart_period` 参数
   - 添加 `dropout_rate` 和 `label_smoothing` 参数
   - 调整学习率和训练轮数

2. **retrieval_module.py**
   - 在 `lr_scheduler_step()` 中实现学习率重启逻辑
   - 在投影层中应用可配置的dropout
   - 在文本编码器中应用可配置的dropout

## 🎓 理论依据

### 为什么学习率重启有效？

1. **跳出局部最优**
   - 模型在0.29处可能陷入"舒适区"
   - 重启学习率相当于给模型"一脚油门"，强制探索新区域

2. **类似集成学习**
   - 每次重启相当于训练一个"子模型"
   - 多次重启的效果类似于多个模型的集成

3. **防止过早收敛**
   - 传统cosine annealing在后期学习率过低
   - 重启机制保持模型的"活力"

### 为什么增强正则化？

1. **防止过拟合**
   - 0.29可能是训练集的"记忆点"
   - 更强的正则化迫使模型学习更泛化的特征

2. **增加随机性**
   - Dropout和Hard Negative Mining增加训练的随机性
   - 帮助模型探索更多可能性

1. **切换到roberta-base**

   - roberta-base更容易训练，可能反而效果更好

   - 添加更多AudioCaps数据

   - 启用交叉注意力机制

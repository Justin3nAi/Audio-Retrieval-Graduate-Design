# 🔥 学习率重启策略 - 突破0.29平台期

## 📊 问题诊断

### 观察到的现象
从你的W&B曲线可以看到：
- **Epoch 0-5**: 快速上升 (0.05 → 0.25)
- **Epoch 5-10**: 缓慢上升 (0.25 → 0.29)
- **Epoch 10+**: **完全停滞** (卡在0.29)

### 根本原因
```
学习率过早衰减 → 模型陷入局部最优 → 无法继续提升
```

**具体分析**：
1. **Warmup期 (0-5轮)**: 学习率从0线性增长到max_lr，模型快速学习
2. **Cosine衰减期 (5-55轮)**: 学习率按余弦曲线衰减
3. **问题**: 到第10轮时，学习率已经衰减到很小，模型失去探索能力

---

## 🚀 解决方案：学习率重启 (Cosine Annealing with Warm Restarts)

### 核心思想
**周期性地将学习率重启到高值，给模型多次跳出局部最优的机会**

| 参数 | 旧配置 (停滞) | 新配置 (重启) | 改进说明 |

## 🔬 原理解释

### 为什么学习率重启有效？

1. **跳出局部最优**
   - 高学习率让模型重新探索参数空间
   - 每次重启都是一次"逃离"的机会

2. **多次优化机会**
   - 相当于进行6次"mini训练"
   - 每次都能找到更好的解

3. **平衡探索与利用**
   - 重启后：高学习率探索新区域
   - 衰减时：低学习率精细优化

### 数学公式

在每个重启周期内，学习率按以下公式计算：

```
η_t = η_min + (η_max - η_min) × 0.5 × (1 + cos(π × t_cur / T_cur))
```

其中：
- `η_t`: 当前学习率
- `η_max`: 最大学习率 (8e-5)
- `η_min`: 最小学习率 (5e-6)
- `t_cur`: 当前周期内的步数
- `T_cur`: 重启周期长度 (12 epochs)

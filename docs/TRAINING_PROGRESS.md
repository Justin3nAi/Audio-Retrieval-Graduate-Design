## 🔍 问题诊断

### 问题1：聚类损失不下降 ❌

**现象**：
```
clustering_loss: 3.90 → 3.92 → 3.91 → 3.91 ...（波动，无下降趋势）
```

**原因分析**：
1. **聚类数量太多**：50个聚类 vs 3839个Clotho样本（每类平均77个样本）
2. **权重太小**：clustering_weight=0.05，模型可能忽略此任务
3. **聚类质量**：可能初始聚类质量不高

**影响**：
- 聚类分类模块未发挥作用
- 预期贡献 +1-2% mAP 未实现

---

### 问题2：在线蒸馏贡献太小 ⚠️

**现象**：
```
online_distill_loss: 0.001（非常小）
```

**原因分析**：
1. EMA教师和学生模型已经非常接近
2. 蒸馏温度可能太高（temperature=2.0）
3. 或者蒸馏权重太低（alpha=0.5）

**影响**：
- 在线蒸馏的稳定性作用有限
- 但不是主要问题（损失小说明教师学生一致性好）

---

### 问题3：学习率未达峰值

**现象**：
```
train/lr: 4e-5（当前）< 5e-5（max_lr）
```

**原因**：
- Warmup期为8个epoch
- Epoch 11刚过warmup，还在爬升阶段

**影响**：
- 学习速度可能偏慢
- 但Epoch 15重启后会改善

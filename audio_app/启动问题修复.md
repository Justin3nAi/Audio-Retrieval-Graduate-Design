# 🚨 应用启动问题修复指南

## 问题诊断

当前遇到的问题：`ImportError: cannot import name 'HfFolder' from 'huggingface_hub'`

这是因为 Gradio 4.39.0 与新安装的 huggingface-hub 1.4.1 版本不兼容。

## 🔧 解决方案

### 方法1：降级 huggingface-hub（推荐）

```bash
cd audio_app
pip install huggingface-hub==0.24.0 --force-reinstall
python audio_caption_app.py
```

### 方法2：升级 Gradio

```bash
cd audio_app
pip install --upgrade gradio
python audio_caption_app.py
```

### 方法3：重新安装所有依赖

```bash
cd audio_app
pip uninstall gradio huggingface-hub -y
pip install gradio==4.39.0 huggingface-hub==0.24.0
python audio_caption_app.py
```
